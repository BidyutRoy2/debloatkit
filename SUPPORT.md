# Support

- **Getting started:** `docs/getting-started.md`
- **Safety questions:** `docs/safety.md` — read before your first `apply`
- **Bugs / package requests:** GitHub Issues (include device model, OS
  version, and the exact package name from `debloatkit inventory`)
- **Restore help:** if `restore` fails, open an issue with your backup
  file's profile and package list (never share your device IP publicly)

Response times are best-effort; this is a community project.
